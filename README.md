Blender-like fly mode navigation for FreeCAD 1.1.x with settings panel, custom keybinds, and custom crosshair. This project has been vibe coded using Claude Sonnet 5.5, and has not been looked over by a competent person.

Default keybind to open settings panel is: Ctrl+Shift+F

Default keybind to enter fly mode is: Shift+F



How to install:

Navigate to the Macro window (1) (2):

<img width="431" height="264" alt="macro_tab" src="https://github.com/user-attachments/assets/ea72f9de-1296-4eec-a8e2-bc9ce1203be2" />

First open folder location (1), then paste the macro file into said folder

<img width="639" height="477" alt="macro_panel" src="https://github.com/user-attachments/assets/e9be492c-d23e-4ddc-98b3-9c4700789df6" />

Then just double-click the macro in the list (2) and it should run, Shift+F to activate/deactivate fly mode, and Ctrl+Shift+F to open the Macro settings panel, to change keybinds and other settings
